# 2026-08-21

## What I Did Today

- Added **Round 0 (Start Type)**: user selects Magic Circle or Slip Knot on PatternHome before entering the editor
- Added **Fasten Off**: a finisher round in Properties that marks the pattern as `finished`, preventing further stitch/row additions
- Updated Pattern type with `startType` and `finished` fields
- Updated PatternHome to show start type selection with radio-style buttons
- Updated Properties to display start type, status, total stitches, and a red Fasten Off button
- Updated Toolbar to disable "Add Stitch" and "New Row" when pattern is finished
- Updated SimpleVisualization to show "Start: Magic Circle/Slip Knot" at the top and "Fasten Off" at the bottom
- Fixed **grouping logic** in SimpleVisualization:
  - Changed from greedy highest-count to longest repeating group
  - Added homogeneous unit skip to avoid `(SC x2) x2` nesting
  - Added fundamental period decomposition to flatten nested repetition (e.g. `(SC,DC) x4` instead of `((SC,DC) x2) x2`)
- Updated `docs/flow.md` with PatternHome flow, Fasten Off flow, and updated component communication table
- Updated `docs/ProjectDiagram.md` with new component tree, sequence diagrams for start type and fasten off

## What I Learned

- The greedy approach for stitch grouping needs to balance "longest group" vs "highest count" — pure longest-group creates nested repetition, pure highest-count breaks up valid groups
- Fundamental period decomposition is the right fix: find the longest group, then check if it's itself a repetition of a shorter unit, and fold the counts
